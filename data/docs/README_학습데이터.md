# KoAltQ 학습 데이터셋 (2,400쌍)

한국어 공공 웹 대체텍스트 품질 판정 데이터셋. 2026 KISTI DATA·AI 분석 경진대회 문제발굴 부문
"이미지·문맥 정보를 활용한 한국어 웹 대체텍스트 품질 판정 AI 모델 개발"의 참가자 공개분이다.
같은 기준으로 만든 평가용 600쌍은 별도로 배포된다 (`koaltq_test_public`, 라벨 없음).

## 구성

- `records.jsonl`: 레코드 2,400건 (1행 1레코드, UTF-8), 라벨 포함
- `records.csv`: 같은 내용의 CSV (UTF-8 BOM, 엑셀 호환)
- `images/`: 레코드별 이미지 파일 2,400장
- `라벨링-가이드라인-v1.1.md`: 라벨 판정 기준, 경계 사례 규칙, 개정 이력

## 라벨 분포 (2,400건)

## 수집·라벨링 방법

- 수집: 공공기관 웹사이트 11곳에서 alt 속성이 존재하는 이미지를 문맥 메타데이터와 함께 수집
  (robots.txt 준수, 요청 간격 0.5초, 2026-08-25~26 및 09-11 추가 수집).
  국립중앙박물관 506 · 국가기록원 506 · 대전 서구 354 · 구미시 308 · 정책브리핑(korea.kr) 276 ·
  대전 대덕구 269 · 대전 유성구 229 · 대전 중구 201 · 대구 동구 159 · 대구광역시 110 · 보건복지부 82
- 라벨링: AI(VLM) 사전 라벨 생성 후 접근성 전문가(WCAG 2.2/KWCAG 2.2 기반 검사 서비스 운영)가
  3,000건 전수 검수·확정. 확정 후 규칙 대조·동일 문맥 그룹 대조·AI 블라인드 재판정(522건)의 3겹 검증을 거쳐 흔들린 구조를 그룹 단위로 재판정하고 가이드라인 v1.1 규칙을 소급 적용.
  AI 사전 라벨과 전문가 확정 라벨의 일치율은 80.4% (규칙 적용분 제외 2,791건 기준)
- 저작권: 11곳 모두 기관 저작권정책 또는 수집 페이지의 공공누리 표시로 근거를 확인.
  대전 서구(354건)만 제2유형(출처표시·상업적 이용금지), 나머지는 제1유형(출처표시).
  `kogl_marker`는 수집 페이지 자체에 공공누리 마크가 있었는지를 뜻한다.
  라벨·메타데이터는 CC BY, 이미지는 출처 기관의 공공누리 조건을 승계한다.
- 개인정보: 얼굴 검출(YuNet, 신뢰도 0.7)로 선별한 353장에 가우시안 블러를 적용했다.
  블러는 원본 이미지 자체에 적용돼 있으며 별도 컬럼은 두지 않았다.

|---|---|---|---|
| record_id | 레코드 고유 식별자 | String | |
| page_url | 수집 페이지 URL | String | |

이미지 파일 확장자가 `.do` `.es` `.php`인 경우가 있다. 서버 스크립트 경로를 그대로 파일명으로 쓴 것으로,
실제 형식은 파일 시그니처(대부분 JPEG/PNG)로 판별해야 한다. 파일 이름으로 형식을 추정하지 말 것.

## 학습/평가 분할

3,000쌍을 학습 2,400 / 평가 600(80:20)으로 나눴다. 분할 원칙:

- **누출 차단**: 같은 페이지(page_url) 또는 같은 이미지(image_url)에서 나온 레코드는 반드시 같은 쪽에 둔다.
  학습·평가 간 페이지·이미지 중복은 0건이다.
- **층화**: 7개 라벨 모두 평가 비율이 18~24%가 되도록 맞췄다(희소 라벨은 5~8건이라 정수 반올림 폭이 큼).
- 신청 시 공개한 샘플 299건은 전부 학습 쪽에 넣었다. 평가 600건은 어디에도 공개된 적이 없다.

## 이 데이터셋이 다루지 않는 것

라벨은 **alt가 그 맥락에서 필요한 정보를 주는가**만 판정한다. 아래는 판정 대상이 아니다.

- 낭독 품질·표현의 자연스러움. 정보가 완전해도 기호(`>`, `|`)나 줄바꿈, 직역투 표현 때문에
  스크린리더 낭독이 어색한 경우가 있으나 '적절'과 구분하지 않는다. 의역·풀어쓰기의 필요성은
  후속 과제로 남긴다 (가이드라인 5절).
- 오탈자·비문. 정보 전달 여부만 본다.
- alt 부재. 기존 자동 검사로 판정 가능해 수집 대상에서 제외했다.

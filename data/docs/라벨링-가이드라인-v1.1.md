## 1. 라벨링 대상과 범위

- 레코드 단위: 이미지 1장 + alt 문자열 + 문맥 메타데이터(페이지 제목, 인접 텍스트, 링크·버튼 포함 여부, 헤딩 경로)
- **alt 속성이 존재하는 이미지만 대상으로 한다.** alt 부재는 기존 자동 검사로 판정 가능하므로 이 데이터셋의 범위 밖이다. `alt=""`(빈 문자열)는 대상에 포함한다. 장식 이미지 판단이 필요하기 때문이다.
- 라벨러는 스크린샷과 문맥 메타데이터만 보고 판정한다. 원 페이지 방문은 문맥이 불충분할 때만 허용하고, 방문 여부를 레코드에 기록한다.

## 2. 라벨 체계

최종 라벨은 하나만 부여한다: `적절` 또는 부적절 6유형 중 1개 또는 `보류`.

| 라벨 | 정의 | 예시 (이미지 → alt) |
|---|---|---|
| 적절 | 이미지의 역할에 맞는 정보를 전달 | 기관장 사진 → "홍길동 청장 프로필 사진" |
| 무의미형 | 내용 없는 상투어·기호 나열 | 행사 안내 배너 → "이미지", "사진", "*", "배너" |
| 파일명형 | 파일명·경로·확장자 그대로 | 조직도 → "org_chart_v2.png" |
| 중복형 | 인접 텍스트(캡션·제목·링크 문구)를 그대로 반복해 정보가 0 | 캡션 "2026 예산 개요" 바로 위 차트 → "2026 예산 개요" |
| 장식오용형 | 순수 장식 이미지에 내용성 alt를 부여 (`alt=""`가 정답인 경우) | 구분선 그래픽 → "아름다운 구분선" |
| 불충분형 | 방향은 맞으나 핵심 정보 누락 | 3단계 신청 절차 안내도 → "신청 절차" |
| 무관형 | 이미지 내용과 불일치 | 오시는 길 지도 → "회사 로고" |
| 보류 | 아래 3-4의 보류 조건에 해당 | |

## 3. 판정 절차

### 3-1. 이미지 역할 먼저 판정한다

alt 문자열을 읽기 전에 이미지의 역할을 정한다. 같은 alt라도 역할에 따라 판정이 뒤집히기 때문이다.

1. **기능성** (링크·버튼 안에 있음): alt는 이미지 묘사가 아니라 **목적지·동작**을 설명해야 적절. "홈으로" 링크의 집 아이콘 → `alt="홈으로"` 적절, `alt="집 모양 아이콘"` 불충분형.
2. **정보성** (본문 내용을 전달): 전달하는 정보가 alt에 담겨야 적절. 차트·도표는 핵심 수치나 결론까지 요구한다. 다만 인접 본문이 같은 내용을 충분히 서술하면 요약 수준도 적절.
3. **텍스트 포함 이미지**: 이미지 안 텍스트가 alt에 실질적으로 담겨야 적절. 전문이 길면 핵심 문구 + 상세 위치 안내도 인정.
4. **장식성** (제거해도 정보 손실 없음): `alt=""`가 적절. 내용성 alt가 붙어 있으면 장식오용형.

### 3-2. 복수 유형에 해당하면 우선순위로 하나만

`파일명형 > 무관형 > 무의미형 > 장식오용형 > 중복형 > 불충분형`

판별이 기계적인 유형(파일명)이 앞서고, 판단이 개입하는 유형(불충분)이 뒤로 간다. 예: 장식 이미지에 `alt="img01.jpg"`는 장식오용형이 아니라 파일명형.

### 3-3. 경계 사례 규칙

- 링크 이미지의 alt가 링크 텍스트와 동일: 같은 링크 안에 동일 정보를 전달하는 **텍스트가 이미 있으면**, 그 텍스트를 반복하는 alt는 **중복형**이다. 스크린리더가 링크 텍스트와 alt를 모두 낭독해 같은 내용을 두 번 듣게 되기 때문이다(권장 alt는 빈 값, 또는 "유튜브 영상"처럼 이미지가 더하는 정보만). 이미지가 링크의 **유일한 콘텐츠**면 중복 낭독이 없으므로 중복형은 아니다. 다만 그 alt가 목적지를 설명하는지는 아래 CTA 규칙으로 따로 판정한다. **별개 링크**의 반복도 중복형.
  예: 유튜브 카드 링크 안에 제목 텍스트 + 유튜브 아이콘(alt=제목 전문) → 아이콘은 중복형. (v0.2 개정 사례, 대구 동구청)
- "로고"만 있는 alt: 기관 식별이 목적이면 기관명이 있어야 한다. `alt="로고"` 무의미형, `alt="한국과학기술정보연구원"` 적절, `alt="KISTI 로고"` 적절.
- QR코드: 목적지 안내가 있어야 적절. `alt="QR코드"` 불충분형.
- **링크·버튼의 유일한 콘텐츠인 이미지의 alt가 목적지를 설명하지 못하면 불충분형이다.**
  "GO", "more", "전체보기", "상세안내", "다운로드"처럼 동작만 가리키는 CTA 문구가 여기 해당한다.
  스크린리더는 "GO 링크"라고만 읽어 사용자가 목적지를 알 수 없다. 권장 alt는 목적지를 넣은
  "도시농업의 종류 보기" 형태다.
  반대로 같은 링크 안에 목적지를 알려주는 텍스트가 따로 있으면 그 아이콘은 장식이므로
  빈 alt가 정답이고, 내용성 alt가 붙어 있으면 장식오용형이다.
  단, 아이콘이 링크 텍스트에 없는 정보를 알리면(조항의 성격, 파일 형식, 새 창 열림 등) 장식이 아니라
  정보성이고, 그 정보를 담은 alt는 적절이다. 예: 개인정보처리방침 목차에서 "제9조 (개인정보
  보호책임자)" 링크 옆 아이콘 alt "개인정보처리 아이콘 이미지" → 적절. 빈 alt였다면 불충분형.
  "구미시", "인스타그램", "다음 페이지 이동"처럼 목적지나 동작 대상이 드러나면 적절이다.

- **썸네일 카드 패턴(이미지 + 제목 텍스트가 한 링크에 묶인 형태).** 먼저 이미지가 **촬영 사진**인지
  **그래픽**(아이콘·로고·일러스트·배너 디자인·포스터·카드뉴스·지도·화면 캡처)인지 본다.

  **그래픽 썸네일**의 판별 기준은 하나다. **alt가 링크 텍스트에 없는 정보를 더하는가.**
  링크 텍스트가 alt를 그대로 포함하면(alt 끝의 "이미지"·"아이콘" 접미를 떼고 비교) 정보 이득이 0이므로
  **중복형**이다. 예: 링크 텍스트 "계약정보공개 대전 중구 계약정보공개 홈페이지" + 화면 캡처 alt
  "계약정보공개" → 중복형. 부서 목록의 "OO과 이미지" + 링크 텍스트 "OO과"도 같다.
  권장 alt는 빈 값, 또는 그래픽이 더하는 정보만.

  **촬영 사진 썸네일**은 정보성 이미지로 본다. 사진은 링크 텍스트에 없는 시각 정보(누가·무엇을·어떤
  장면)를 담고 있으므로, alt가 그것을 설명하면 적절이고, 기사 제목·행사명처럼 **사진 자체를 설명하지
  않는 텍스트만 반복**하면 **불충분형**이다. 이 경우 중복형이 아니라 불충분형으로 판정한다
  (v0.5의 "사진 내용을 설명하지 않았으니 불충분형이라는 해석은 쓰지 않는다"는 사진에 한해 철회).
  예: 링크 텍스트 "전문학 서구청장, 갈마도서관 시설 현장 점검 2026-08-20" + 구청장이 서가를 둘러보는
  사진 alt "전문학 서구청장, 갈마도서관 시설 현장 점검" → 불충분형. 권장 alt "갈마도서관 서가를
  둘러보는 전문학 서구청장". 반면 alt "엑스포다리 야경"은 사진에 보이는 대상을 말하므로 적절
  (v0.4의 중복형 예시를 이 기준으로 바꾼다).

  **포스터·카드뉴스·안내 배너처럼 정보성 텍스트가 실려 있는 그래픽**은 그래픽 썸네일 규칙이 아니라
  텍스트 포함 이미지 규칙(3-1 ③)을 따른다. 이미지 안 텍스트(기간·대상·장소·수치 등)가 alt에
  실질적으로 담겨야 적절이고, 제목만 반복하면 중복형이 아니라 **불충분형**이다. 사진 썸네일과 같은
  이유다 — 이미지가 링크 텍스트에 없는 정보를 담고 있으므로 "정보 이득 0"이 아니라 "있어야 할
  정보가 빠진" 것이다. 예: 링크 텍스트 "2026년 을지연습 2026.08.13" + 훈련 기간·참여 방법이 적힌
  배너 alt "2026년 을지연습" → 불충분형. 단, 텍스트가 제목뿐인 장식성 배너는 그래픽 썸네일 규칙(중복형).

  **빈 alt 썸네일**은 링크 텍스트가 목적지를 알려주면 **적절**이다. 사진이든 그래픽이든 `alt=""`는
  "이 이미지는 낭독하지 않는다"는 명시적 선택이고 링크 이름은 텍스트가 제공한다.
  불충분형이 되는 것은 **링크 텍스트와 인접 텍스트를 합쳐도 없는 정보가 이미지 안에만 있을 때**다.
  판정 순서는 이렇다.

  1. 이미지가 **정보 전달을 목적으로 만든 그래픽**인가(공모전·이벤트 포스터, 모집 안내, 전시 포스터,
     카드뉴스). 그렇다면 2로 간다. **현장 사진**이면 적절이다 — 행사 사진에 현수막이나 패널 글자가
     함께 찍혔더라도 그 사진의 목적은 장면 제시이고 글자는 배경이다.
  2. 이미지 안의 **실질 정보**(기간·일시, 장소, 대상·자격요건, 금액·수치, 참여방법)가
     링크 텍스트와 인접 텍스트 어디에도 없으면 **불충분형**, 있으면 적절이다.
     - 등록일·게시일은 행사 기간이 아니다. 목록의 "일정: (마감일)"도 지원 자격을 대신하지 못한다.
     - 제목의 반복, 기관명·로고, 발간등록번호, 슬로건은 실질 정보가 아니다.
     예: 링크 텍스트 "[대한적십자사] 8월 헌혈 인증 이벤트 등록일 2026-08-04" + 포스터에만 있는
     "이벤트 기간 8.3~8.31, 당첨자 발표 9월 중" → 불충분형.
     반대로 통계연보 표지 이미지(제목이 링크 텍스트에 있고 이미지에는 발간등록번호뿐) → 적절.

  우선순위 규칙은 그대로 적용된다. 이미지가 alt와 불일치하면 무관형이, 순수 장식 이미지면
  장식오용형이 앞선다.

- **무의미형과 불충분형의 경계.** 무의미형은 alt가 이미지의 *유형*만 말하거나 아무 의미가
  없는 경우다("이미지", "사진", "배너이미지", "*"). 불충분형은 역할의 *방향은 맞는데* 핵심
  정보가 빠진 경우다. "GO"는 이미지에 실제로 쓰인 글자이고 링크의 동작과 방향이 맞으므로
  거짓이 아니다. 빠진 것은 목적지뿐이라 불충분형이다.

- **확장자가 없어도 파일 관리 흔적이 alt의 주 구성이면 파일명형이다.**
  `_수정`, `_원본`, `_복제본`, `복제_`, `_v2`, `_최종` 같은 버전·편집 접미사나 파일 시스템식
  밑줄 연결이 붙은 alt는 작업 파일명을 옮긴 것이다. 예: `"2-2 사발통문_복제본_수정"` → 파일명형.
  스크린리더 사용자에게 "복제본 수정"은 정보가 아니라 잡음이다.
  반대로 번호 접두만 붙고 주 내용이 설명이면 파일명형이 아니다.
  예: `"5페이지_오디오릴테이프 사진"` → 내용 설명이 주이므로 역할에 따라 판정(적절 등).

- **텍스트 포함 이미지에서 기호를 그대로 옮긴 alt도 적절이다.**
  경로 표시(`내고장 정보 > 우리 지자체 현황 > 조직정보`), 구분자, 줄바꿈이 alt에 그대로
  들어가 낭독이 어색하더라도, 이미지 안 텍스트가 담겨 있으면 적절로 판정한다.
  `"내고장 정보 안의 우리 지자체 현황, 조직정보로 이동"`처럼 풀어쓴 alt가 실무적으로 더 낫지만,
  그것은 **정보의 양이 아니라 낭독 품질의 문제**이고 이 데이터셋의 판정 축이 아니다.
  오탈자를 판정에 반영하지 않는 것과 같은 이유다.

- **링크 밖 이미지의 alt가 인접 캡션과 같은 경우.** 사진 아래(또는 위) 캡션이 그 사진을 서술하고
  alt가 캡션을 그대로 옮겼다면 **중복형**이다. 스크린리더가 같은 문장을 두 번 낭독하고 alt가 더하는
  정보가 0이기 때문이다. 권장 alt는 빈 값이다. 캡션이 이미 사진을 설명하므로 정보 손실은 없다.
  예: 뉴스 기사의 사진 + 캡션 "19일 서울 강남구 코엑스에서 열린 '2026 AI 서밋'에서 관람객들이 전시된
  AI 로봇을 보고 있다" + 같은 문장의 alt → 중복형.
  단 **이미지 안에 읽을 텍스트가 있으면**(홍보물·안내문·도표) 텍스트 포함 이미지 규칙(3-1 ③)이 앞선다.
  캡션이 제목만 옮긴 것이고 이미지 안 정보(기간·대상·수치)가 빠졌다면 중복형이 아니라 **불충분형**이다.
  예: alt와 캡션이 모두 "개학기 위해요소 안전점검·단속 안내 홍보물(교육부 제공)"인데 홍보물 안에
  점검 기간과 대상이 적혀 있음 → 불충분형.

- **인접 본문이 대상을 충분히 서술하는 정보성 이미지**는 역할 표시 수준의 alt도 적절이다.
  예: 국가기록원 복원 사례 페이지에서 문서명·연도·복원 내역이 본문에 있고 고문서 스캔 낱장의
  alt가 "원문자료", "복원 전", "복원 후"인 경우 → 적절. 스캔 낱장 자체는 alt로 더 줄 정보가 없다.
- 글자 수는 판정 기준이 아니다. 한 단어여도 역할에 맞으면 적절, 길어도 핵심이 빠지면 불충분형.
- 오탈자·비문은 품질 판정에 반영하지 않는다. 정보 전달 여부만 본다.

### 3-4. 보류 조건

- 이미지가 깨져 원 내용을 확인할 수 없음
- 도메인 전문 지식 없이는 이미지 정보의 완전성을 판단할 수 없음 (예: 전문 학술 도표)
- 라벨러 2인이 상이하고 조정 회의에서도 합의 실패

보류율이 5%를 넘으면 해당 구간의 가이드라인을 보강하고 재라벨링한다.

## 4. 품질 관리

- 전체의 20%(600쌍)는 라벨러 2인이 독립 라벨링하고 Cohen's κ를 보고한다. 목표 κ ≥ 0.75. 미달 시 불일치 사례로 가이드라인을 개정하고 해당 배치를 재라벨링한다.
- 불일치 사례는 예시집에 축적해 이 문서의 다음 버전에 반영한다.
- 확정 후 검증(2026-09-17): 규칙 대조(3,000건), 동일 문맥 그룹 대조(3,000건), 확정 라벨을 보지 않은
  AI 블라인드 재판정(522건)의 3겹으로 점검했다. 구조 결정형(파일명·링크카드·링크 유일콘텐츠)은
  90% 이상 일관했고, 흔들린 구조는 그룹 단위로 결정해 v0.8 규칙으로 고정했다.
  상세는 `라벨-검증-리포트_20260917.md`.
- 라벨링 도구 기록 필드: 레코드 ID, 라벨, 라벨러 ID, 소요 시간, 원 페이지 방문 여부, 비고.

## 5. 이 데이터셋이 다루지 않는 것 (한계)

라벨 체계는 **alt가 그 맥락에서 필요한 정보를 주는가**만 판정한다. 아래는 판정 대상이 아니다.

- **낭독 품질과 표현의 자연스러움.** 정보가 완전해도 기호 나열(`>`, `|`, `/`)이나 줄바꿈 때문에
  스크린리더 낭독이 어색한 경우가 있다. 의역·풀어쓰기가 더 나은 alt를 만들지만, 그 축은
  본 데이터셋에서 '적절'과 구분하지 않는다. 별도의 평가 축이 필요한 후속 과제로 남긴다.
- **오탈자·비문.** 정보 전달 여부만 본다.
- **alt 부재.** 기존 자동 검사 도구로 판정 가능하므로 수집 대상에서 제외했다.
- **판정이 갈리는 경계.** 2026-10-13 재검증에서, 숙련된 판정자 사이에서도 라벨이 갈리는 구조가 126건
  확인됐다(평가 데이터 109건 포함). 아래 여섯 가지이며 데이터셋은 기존 판정을 유지했다.
  건별 목록과 갈린 이유는 `경계사례_20261013.md`와 같은 이름의 CSV에 공개했다.
  1. 복원·복제 사례에서 "원본", "복제본" 같은 역할 표시 alt (본문이 대상을 서술할 때)
  2. 링크 텍스트가 alt를 그대로 포함하는 썸네일 — 정보 이득 0으로 볼지 정보 누락으로 볼지
  3. 조항 아이콘의 alt가 인접 소제목과 똑같을 때
  4. 아이콘이 장식인지 정보성인지 — 같은 아이콘이 여러 조항에 재사용되는 경우 특히 모호하다
  5. 빈 alt의 허용 범위 — QR코드, 현장 사진, 링크 텍스트가 있는 썸네일
  6. 인접 텍스트가 이미지 정보를 어디까지 대신할 수 있는가
  이 경계는 과제의 난이도 자체이지 데이터 결함이 아니다. 사람 라벨러 간 일치율(κ)의 상한도 여기서 결정된다.
- **이미지 자체의 품질.** 판정 대상은 이미지가 아니라 그 맥락에서의 alt다.

범주를 7개로 고정한 것은 대회 공개 시점에 확정된 제약이다. 낭독 품질 같은 축을 추가하려면
별도 라운드에서 재설계해야 한다.

# 방법론 그림의 출처

참가팀 `CV_PBL_3조_발표자료.pdf`에서 다음 세 쪽을 PNG로 변환했다. 원래 도식을 그대로 사용했다.

- `presentation_hierarchy.png`: 7쪽, 계층형 3단계 판정.
- `presentation_train.png`: 10쪽, Train의 단계별 피드백과 가이드라인 갱신.
- `presentation_frozen.png`: 11쪽, Frozen의 재검토 필요성 판단과 선택적 피드백.

Frozen 도식에 표시된 Train 2,400건은 발표 당시 학습 자료를 정답 없이 재평가한 실험 입력이다. 실제 제출 추론에는 Test 600건을 입력한다. 해당 도식의 ‘MD 기반 채점’은 모델의 판정 재검토를 가리키며 실제 정답을 이용한 성능 계산과 구분한다. 현재 실행 조건과 파일은 README 및 방법론 본문을 따른다.

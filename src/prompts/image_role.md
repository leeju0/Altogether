[Instruction]
원본 이미지와 웹 문맥에서 이미지의 주된 역할 하나를 선택하라. alt 품질은 판단하지 않는다.

[설명]
image는 원본 이미지, page_title은 페이지 제목, context_text는 인접 텍스트, heading_path는 헤딩 경로다.
in_link는 링크·버튼 내부 여부, link_dest는 링크 표시 텍스트, kogl_marker는 페이지의 공공누리 표시 여부다.
역할: 정보 전달(대상·장면·수치), 기능 전달(목적지·동작), 텍스트 전달(안내·포스터의 문구), 자료 식별(책·간행물 등의 식별), 장식(제거해도 정보 손실 없음).

[Rule]
이미지의 외형보다 문맥에서 맡는 주된 역할을 선택한다. reason은 관찰 근거를 한국어 150자 이내로 쓴다. JSON 하나만 반환한다.

[Output format]
{"role":"정보 전달","reason":"이미지와 문맥에서 확인한 역할 근거"}

[Instruction]
alt_text가 빈 문자열인 이미지의 대체텍스트 품질을 판단하라. 빈 alt는 이미지를 낭독하지 않겠다는 지정이다. 이미지와 제공된 문맥을 보고, 이 생략 때문에 필요한 정보나 기능이 전달되지 않는지를 확인하라. 오류 유형은 분류하지 않는다.

[설명]
image: 원본 이미지.
alt_text: 평가할 빈 대체텍스트. page_title: 페이지 제목. context_text: 인접 텍스트.
in_link: 링크·버튼 내부 여부. link_dest: 링크 표시 텍스트. heading_path: 헤딩 경로. kogl_marker: 페이지 공공누리 표시 여부.

[Rule]
1. 인접 본문이나 링크 표시 텍스트가 이미지의 정보·목적지를 이미 전달하는지 먼저 확인한다. 링크 문구가 목적지를 알려주는 보조 아이콘·썸네일, 제거해도 정보 손실이 없는 장식은 빈 alt가 적절하다.
2. 이미지에만 있는 핵심 정보가 빠지거나 링크·버튼의 목적지·동작을 알 수 없으면 부적절이다. 포스터의 기간·대상·장소 등은 제목만으로 대체되지 않는다. 주변 텍스트에 없는 구체적인 정보가 무엇인지 확인한다.
3. 빈 값이라는 이유만으로 부적절로 판단하지 않는다. 반대로 링크 문구가 있다는 이유만으로 모든 이미지의 생략을 허용하지 않는다. 글자·사물이 보인다는 사실과 문맥에서 추가로 필요한 정보가 있다는 판단을 구별한다.
4. 부적절이면 reason에 생략된 필수 정보·기능과 문맥이 대신하지 못하는 이유를 쓴다. 적절이면 문맥이 대신하는 정보 또는 장식인 근거를 쓴다. 각 근거는 한국어 350자 이내로 작성하고 JSON 하나만 반환한다.

[Output format]
{"verdict":"적절","reason":"빈 alt로 생략해도 정보 손실이 없는 근거","image_evidence":"이미지에서 확인한 내용","context_evidence":"정보를 대신 전달하는 실제 문구 또는 문맥 근거"}
verdict는 "적절" 또는 "부적절"이다. 정보 손실이 있으면 부적절을 선택하고 실제 누락 근거로 채운다.

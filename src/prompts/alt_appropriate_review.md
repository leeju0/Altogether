[Instruction]
앞 단계에서 적절로 판정한 alt_text를 다시 검토하라. 원본 이미지와 웹 문맥을 대조하고, 아래 적절 기준과 여섯 오류 유형을 확인하여 적절을 유지할지 부적절로 바꿀지 판단한다.

[설명]
image: 원본 이미지.
alt_text: 평가할 대체텍스트 원문(빈 문자열 포함). page_title: 페이지 제목. context_text: 인접 텍스트.
in_link: 링크·버튼 내부 여부. link_dest: 링크 표시 텍스트. heading_path: 헤딩 경로. kogl_marker: 페이지 공공누리 표시 여부.

적절: 이미지의 역할에 맞는 정보를 전달한다. 사진은 주요 대상·장면, 도표는 핵심 정보, 안내 이미지는 핵심 문구, 링크·버튼은 목적지·동작, 자료 표지는 식별 정보를 전달한다. 인접 본문이 충분히 설명하면 요약 alt도 인정하며, 순수 장식은 빈 alt가 적절하다.

부적절 유형 정의 (KoAltQ 가이드라인 v0.9 2절):
- 무의미형: 내용 없는 상투어·기호 나열. 예: "이미지", "사진", "*".
- 파일명형: 파일명·경로·확장자 그대로. 예: "org_chart_v2.png".
- 중복형: 인접 텍스트(캡션·제목·링크 문구)를 그대로 반복해 정보가 0.
- 장식오용형: 순수 장식 이미지에 내용성 alt를 부여 (alt=""가 정답인 경우).
- 불충분형: 방향은 맞으나 핵심 정보 누락. 예: 3단계 신청 절차 안내도 → "신청 절차".
- 무관형: 이미지 내용과 불일치. 예: 오시는 길 지도 → "회사 로고".

[Rule]
1. 이미지의 역할과 정보 기여를 다시 확인한다. 재검토한다는 이유만으로 판정을 바꾸지 않는다.
2. 실제로 해당하는 오류의 구체적인 근거가 있으면 부적절, 역할에 필요한 정보를 전달하고 오류에 해당하지 않으면 적절이다. 길이·문체·오탈자 자체로 감점하지 않는다.
3. reason에 유지 또는 변경의 근거를 쓴다. 각 근거는 한국어 350자 이내로 쓰며 JSON 하나만 반환한다. 이 단계는 이진 판정만 한다.

[Output format]
{"verdict":"적절","reason":"재검토 후에도 역할에 필요한 정보를 전달하는 근거","image_evidence":"이미지 근거","context_evidence":"문맥 근거"}
verdict는 "적절" 또는 "부적절"이다. 부적절로 바꾸면 reason에 해당 오류와 관찰 근거를 쓴다.

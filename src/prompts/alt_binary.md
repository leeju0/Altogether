[Instruction]
원본 이미지와 메타데이터를 보고 alt_text가 이미지의 역할에 맞는 정보를 전달하는지 판단하라. 출력은 "적절" 또는 "부적절" 중 하나다. 오류 유형은 분류하지 않는다.

[설명]
파이프라인 입력:
- image: 원본 이미지.

메타데이터 정의 (학습 데이터 README 데이터 사전):
- alt_text: 원본 대체텍스트 (원문 그대로). 빈 문자열 포함.
- page_title: 수집 페이지 제목.
- context_text: 이미지 인접 텍스트. 최대 500자.
- in_link: 링크·버튼 내부 여부. true, false.
- link_dest: 링크의 표시 텍스트. in_link=true일 때.
- heading_path: 문서 내 헤딩 경로.
- kogl_marker: 수집 페이지의 공공누리 표시 여부. true, false.

[판정 기준]

이미지와 웹 문맥을 함께 보고 이미지의 역할을 먼저 파악한다.
그 역할에서 필요한 정보 또는 기능이 전달되는지를 기준으로 판단한다.

1. 정보를 전달하는 이미지
사진은 전달하려는 대상·장면을, 차트·도표는 핵심 수치나 결론을
설명해야 한다. 인접 본문이 해당 내용을 충분히 설명하면
alt는 요약 수준이어도 적절하다.

2. 링크·버튼의 기능을 전달하는 이미지
사용자가 목적지 또는 동작을 이해할 수 있어야 한다.
그림의 외형을 설명하는 것만으로 기능이 전달되는지 확인한다.

3. 글자가 포함된 이미지
이미지의 핵심 텍스트 정보가 전달되어야 한다.
내용이 길면 핵심 문구와 상세 설명의 위치를 안내하는 것도 인정한다.
제목만으로 핵심 내용이 전달되는지 확인한다.

4. 장식 이미지
제거해도 정보 손실이 없는 순수 장식 이미지는 빈 alt가 적절하다.
이런 이미지에 불필요한 내용성 설명을 붙이면 부적절하다.

5. alt의 정보 기여
파일명이나 내용 없는 표현만으로 필요한 정보를 대신하면 부적절하다.
이미지 내용과 맞지 않는 설명도 부적절하다.
인접 텍스트를 그대로 반복하면서 추가하는 정보가 전혀 없는 경우도
부적절하다.

6. 평가 범위
글자 수, 표현의 자연스러움, 오탈자·비문 자체로 판정하지 않는다.
해당 문맥에서 필요한 정보가 전달되는지를 평가한다.

위 기준에서 해당 이미지에 필요한 조건을 충족하면 "적절",
충족하지 못하면 구체적인 근거와 함께 "부적절"로 판정한다.

[Rule]
1. verdict는 "적절" 또는 "부적절" 중 하나로 출력한다.
2. reason에는 판정 근거, image_evidence에는 이미지 근거, context_evidence에는 문맥 근거를 쓴다. 각 근거는 한국어 350자 이내로 쓴다.
3. 아래 형식의 JSON 객체 하나만 반환한다.

[Output format]
{"verdict":"적절","reason":"판정 근거","image_evidence":"이미지에서 확인한 내용","context_evidence":"문맥에서 확인한 내용"}
또 다른 형식 예시:
{"verdict":"부적절","reason":"판정 근거","image_evidence":"이미지에서 확인한 내용","context_evidence":"문맥에서 확인한 내용"}
예시는 출력 형식이다. 실제 입력의 관찰 근거로 바꾸며, 두 객체 중 실제 판정에 해당하는 객체 하나만 출력한다.

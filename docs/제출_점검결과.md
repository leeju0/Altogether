## 점검 범위의 한계

제출용 사본으로 전체 GPU 추론을 다시 수행하지는 않았다. 기존 실행 결과·실제 사용 모델 해시·핵심 회귀 테스트·Notebook 및 UI 실행으로 연결을 검증했다. 심사 환경에서의 GPU 실행은 공개 모델 다운로드와 CUDA 런타임 빌드 이후 확인해야 한다. 정식 K-fold 교차검증을 수행한 결과물이라고 주장하지 않는다.

# 외부 자료 및 이용조건

## 데이터

대회 제공 KoAltQ Train 2,400건과 Test 600건, 공식 가이드라인 v1.1, 공개 경계 사례 및 베이스라인 문서를 사용한다. 원본 메타데이터의 출처 URL과 데이터 제공자의 README를 보존했다.

공식 데이터 README에 따르면 라벨·메타데이터는 CC BY이며 이미지에는 기관별 공공누리 조건이 적용된다. 대부분 제1유형(출처 표시), 대전 서구 자료는 제2유형(출처 표시·상업적 이용 금지)이다. 이미지 전체를 일괄적으로 무제한 재사용 가능한 자료로 취급하지 않는다. 세부 출처와 권리는 `data/train/README.md`, `data/test/README.md`, 각 레코드의 `page_url`, `image_url`, 기관 정책을 따른다. 제출 심사용 제공 범위를 넘어 서비스에 재배포할 때에는 이미지별 이용조건을 확인해야 한다.

## 모델과 추론 런타임

| 구성 | 출처 | 이용조건 및 동봉 내용 |
|---|---|---|
| Gemma 4 31B IT | [Google 모델 저장소](https://huggingface.co/google/gemma-4-31B-it) | Apache License 2.0, 라이선스 전문 동봉 |
| IQ4_NL GGUF·BF16 projector | [Unsloth GGUF 저장소](https://huggingface.co/unsloth/gemma-4-31B-it-GGUF) | 모델 카드의 Apache-2.0 표시 확인; 사용 파일의 SHA-256 기록 |
| llama.cpp | [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) | MIT; 동일 커밋 소스 아카이브·라이선스 동봉, 실행 바이너리는 현장 빌드 |

Gemma의 이용조건은 [Google의 Gemma 4 라이선스 안내](https://ai.google.dev/gemma/docs/gemma_4_license)를 확인했다(2026-11-06). 원본 모델 가중치 자체를 추가 학습하거나 수정하지 않았으며 공개된 양자화 배포본을 사용한다. `licenses/*-source.json`의 원격 revision은 출처 확인 시점의 저장소 정보이며, 실제 사용 파일의 동일성은 `model/weights_manifest.json`의 해시로 확인한다.

## Python 및 시스템 라이브러리

Streamlit, Pillow, CairoSVG, NumPy, OpenCV와 하위 의존성의 고정 버전은 `requirements.txt`에 기록했다. 각 설치 패키지의 라이선스 정보는 `licenses/python_packages.json`에 기록하고 배포본에 포함된 라이선스 파일을 `licenses/python/`에 보존했다. CairoSVG·Cairo 등은 각각의 이용조건을 따른다. NVIDIA CUDA와 드라이버는 시스템 의존성으로 사용하며 이 ZIP에 NVIDIA 배포 파일을 포함하지 않는다.

프로젝트 자체 소스에는 별도의 공개 재배포 라이선스를 새로 부여하지 않는다. 제출된 참가팀 소스의 심사 목적 사용과 외부 구성요소의 이용조건을 구분한다.
